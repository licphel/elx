ELX language reference

ELX Language Manual

A practical reference for the embeddable, register-based scripting language used by the ELX runtime.

This first edition is a navigation shell for the manual. It follows the familiar progression of a language reference: concepts, syntax, runtime behavior, host integration, and appendices.

ELX keeps functions and tables as first-class values, adds explicit integer and floating-point widths, and exposes managed memory through a checked pointer model.

Quick start

ELX source is compiled into a validated prototype and executed by a host-owned VM. A small function can be written like this:

local function twice(value) {
  return value * 2
}

return twice(21)

Named function declarations and function assignments share the same runtime model. A table method uses the receiver form:

local counter = { value = 0 }
function counter:next() {
  self.value += 1
  return self.value
}
